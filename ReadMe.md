## 🚀 Projects

- **[tfguard](https://github.com/SamyBaouche/tfguard)**: Go CLI that reviews Terraform plans for risk, security, and cost, and gates CI before an unsafe apply ships. 5 OPA/Rego policies, Checkov/tfsec, and a risk classifier trained on about 250 plans.
- **[neuroops](https://github.com/SamyBaouche/neuroops)**: self-healing Go service on Kubernetes. Recovers from a failed pod in about 10 s, scales from 1 to 5 pods under load, and stands up from a single `terraform apply`.
- **[zero-trust-cloud](https://github.com/SamyBaouche/zero-trust-cloud)**: Spring Boot and React access control app on AWS. Policy engine returns ALLOW / CHALLENGE / DENY in about 3 ms with a full audit trail.
- **[ml-cat-dog](REPO_URL_HERE)**: MobileNetV2 image classifier at 97% accuracy, served through FastAPI at about 60 ms per prediction and deployed to AWS ECS.
